# Generated script packages

`Build-LocalUTGame.ps1` writes the source-built packages to this directory:
`Core.u`, `Engine.u`, `GFxUI.u`, `IpDrv.u`, `GameFramework.u`, `UnrealEd.u`, `WinDrv.u`,
`OnlineSubsystemPC.u`, and `UTGame.u`.

Do not copy similarly named `.u` files from the supplied UDK template trees.
Their package headers and native class graphs are not a substitute for outputs
compiled against this source tree.
